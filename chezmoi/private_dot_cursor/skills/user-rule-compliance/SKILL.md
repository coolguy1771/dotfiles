# Instruction compliance

- Follow all **user**, **tool**, **system**, and **skill** instructions completely.
- When a skill, rule, or tool specifies a format, workflow, or constraint, follow it; treat those constraints as requirements, not suggestions.
- Use **Context7 MCP** for library or API documentation, setup, or configuration when you would otherwise rely on potentially stale training data.
